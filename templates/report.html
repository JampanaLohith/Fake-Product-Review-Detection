B.Tech Capstone Project Documentation Report

Deceptive Opinion Spam Detection Using Hybrid Machine Learning & Explainable AI (XAI)

An Offline-First Lexicon-Stylometric Feature Fusion Classification Engine

Academic Curriculum: B.Tech CSE / AI-ML
Core Stack: Flask, SQLite, Scikit-Learn
System Status: Complete & Verified

1. Abstract

With the exponential expansion of global e-commerce, consumer reviews have transitioned into a critical benchmark governing purchasing decisions. Consequently, online platforms have become vulnerable targets for deceptive opinion spam—fake reviews written maliciously to hype up (promote) or denigrate (demote) products. Traditional NLP approaches often fail to detect deceptive text because paid human writers can mimic genuine language syntax.

This project introduces a robust, offline-first classification framework that fuses Lexical Features (TF-IDF bag-of-words), Stylometric Features (structural writing signatures), and Sentiment Extremity Mismatch Metrics (via NLTK VADER). By concatenating these diverse feature representations, we train a Logistic Regression model as our explainable baseline and compare it against an ensemble Random Forest classifier. Crucially, we incorporate Explainable AI (XAI) to trace local feature contributions, demystifying the model's predictions. The architecture is integrated into a multi-device Flask dashboard backed by a local SQLite history registry.

2. System Architecture & Methodology

The project methodology is divided into five logical stages executed sequentially upon text input:

  1. Text Preprocessing: Normalization (lowercasing), noise removal (stripping punctuations), stopword elimination (via NLTK corpus), and morphological word-lemmatization (via WordNet Lemmatizer).
  2. Dense Stylometric Extraction: Mathematical computation of text structure metrics: character count, uppercase capitalization count, exclamation density, and average word length.
  3. Sentiment Intensity Extraction: Running VADER (Valence Aware Dictionary and Sentiment Reasoner) to generate positive and negative polarity weights.
  4. Feature Space Fusion: Horizontal stack concatenation (scipy.sparse.hstack) of normalized sparse TF-IDF matrices and dense scaled structural matrices.
  5. Relational Database Audit: Recording prediction outcomes and raw text logs in SQLite, while displaying feature weights explanations dynamically.

3. Mathematical Formulations

A. TF-IDF Representation

Term Frequency-Inverse Document Frequency represents word importance:

$$\text{TF}(t, d) = \frac{f_{t,d}}{\sum_{t' \in d} f_{t',d}} \quad , \quad \text{IDF}(t, D) = \log\left(\frac{1 + |D|}{1 + |\{d \in D : t \in d\}|}\right) + 1$$ $$\text{TF-IDF}(t, d, D) = \text{TF}(t, d) \times \text{IDF}(t, D)$$
B. Logistic Regression Probability Modelling

Predicts the probability of a review being Fake (\(y=1\)) utilizing the Sigmoid function:

$$P(y=1|\mathbf{x}) = \sigma(\mathbf{w}^T \mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x} + b)}}$$

Where \(\mathbf{w}\) represents the model coefficient weights vector and \(\mathbf{x}\) represents the fused feature spaces vector.

C. Explainable AI Local Attribution

Local explainability evaluates the contribution \(c_i\) of a specific feature \(x_i\):

$$c_i = x_i \cdot w_i$$

If \(c_i > 0\), the feature acts as an indicator of **Fake** reviews. If \(c_i < 0\), it acts as an indicator of **Genuine** reviews.

4. Model Evaluation & Benchmarking

Our training pipeline executes a 5-fold cross-validation grid search to train and save the optimal model. The experimental outcomes are:

Classification Model Test Accuracy Precision (Fake) Recall (Fake) F1-Score
Logistic Regression (Primary Model) 95.14% 94.74% 95.50% 95.12%
Random Forest Classifier 93.06% 92.11% 94.00% 93.04%

*Note: Logistic Regression was selected as the active model due to superior test accuracies and transparent, linear feature explainability mapping.*

5. Directory & File Blueprint

Explanation of the core code files:

  • `app.py`: Application orchestrator setting up Flask routing, SQLite connection layers, database migrations, and active LAN port bindings.
  • `model.py`: Contains raw text preprocessing pipelines, VADER sentiment binds, stylometric counters, local explainers, and Amazon/Flipkart URL parser regex routines.
  • `download_nltk_github.py`: Utility script to download NLTK corpuses from Raw GitHub CDN, bypassing slow download mirror servers during cloud container builds.
  • `train_model.py`: Mock dataset generator (720 records), training and serialization of pickles (`model.pkl`, `vectorizer.pkl`, `scaler.pkl`).
